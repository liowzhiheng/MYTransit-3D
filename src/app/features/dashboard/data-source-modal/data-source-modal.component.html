Data Sources & System Architecture

Serverless Architecture

MYTransit 3D runs entirely client-side as a static web application deployed on GitHub Pages. Transit corridors and stations are ingested from official Malaysian government open data endpoints, normalized, and rendered interactively using WebGL vector tiles.
